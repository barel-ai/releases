# Barel downloads

Public **notarized DMG** builds of [Barel](https://barel.ai) for the Mac (formerly ModelCaddy).

The app source is private. This repository exists so anyone can download the Mac app without a GitHub login.

## Latest Mac app

**[Download Barel.dmg](https://github.com/barel-ai/releases/releases/latest/download/Barel.dmg)**

That URL always points at the newest release. Versioned copies sit on the same Release.

## Chrome extension

**[Download Barel-Extension.zip](https://github.com/barel-ai/releases/releases/latest/download/Barel-Extension.zip)**, unzip it and keep the folder, then in `chrome://extensions` turn on Developer mode, click Load unpacked and pick the folder.
